# LootZone

واجهة عربية لسوق منتجات وخدمات الألعاب الرقمية.

الإصدار الحالي: **Release Candidate 2.4.0**

تتضمن المعاينة سوق الإعلانات، البحث والفلاتر، الحسابات المحلية، الأخبار، طلبات الإعلانات التجارية، لوحة إدارة تجريبية، وخياري طلب مباشر أو محمي.

> تنبيه: هذه نسخة معاينة ثابتة. الدفع والتسليم والمصادقة الخادمية وقاعدة البيانات غير مفعلة، ولا يجوز استخدامها لاستقبال معاملات حقيقية قبل استكمال متطلبات الإطلاق الموضحة في `READINESS_REPORT_AR.md`.
